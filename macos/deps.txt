## 副作用：openssl CLI 被切换到 4.x

安装 `openssl@4`（python@3.14 依赖）时，Homebrew 执行了：

```
Unlinking /opt/homebrew/Cellar/openssl@3/3.6.4... 6570 symlinks removed.
```

因此 `/opt/homebrew/bin/openssl` 现在指向 **OpenSSL 4.1.0**，`openssl@3` 仍安装但未链接。
如果依赖 openssl 3 的命令行工具出现问题，可恢复：

```bash
brew unlink openssl@4
brew link --force openssl@3
```

（不会影响 python@3.14，它用的是自己的 keg 路径。）
